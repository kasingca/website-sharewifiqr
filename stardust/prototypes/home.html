What you get

Everything a guest Wi-Fi card should do

Make a code once, put it where people will see it, and stop answering "what's the Wi-Fi?"

  • Every kind of network

    WPA, WPA2 and WPA3, older WEP routers, open networks, and hidden networks that don't broadcast their name.

  • See how often it's scanned

    Tracked codes count every scan, so you know whether the card on the wall is being used.

  • Change the password, keep the code

    Update a tracked code's network details in the portal. The card you already printed keeps working.

  • Ready to print

    Download a sharp image or a print-ready card to frame, laminate, or stand on a table.

  • Private by default

    A direct code holds your network inside the QR itself. Nothing is sent to us when a guest scans it.

  • All your codes in one place

    Home, cottage, office: manage every code from one portal account.

How it works

Three steps, about a minute

  1. Enter your network

    Type your Wi-Fi name and password and pick the security type. Not sure which? It's usually WPA2, and it's often printed on the router.

  2. Choose your code

    A direct code joins in one tap. A tracked code counts scans and lets you change the password later.

  3. Print it and share

    Download it, print it, and put it where guests will see it. Watch the scans add up in your portal.

Two kinds of code

Pick what matters to you

Phones can only join a network straight from the camera when the details are inside the code. Counting scans needs a link instead. So we offer both.

  • Direct code

    Joins in one tap

    Your network name and password live inside the QR. The phone offers to join as soon as the camera sees it.

    • One-tap join on iPhone and Android
    • Works without the internet, forever
    • Nothing is logged when it's scanned
    • No scan counts
    • Reprint it if your password changes
  • Tracked code

    Counts every scan

    The QR opens a short Share Wifi QR link that shows your network and password with a one-tap copy button.

    • See how many times it's been scanned
    • Change the password without reprinting
    • Switch it off whenever you like
    • Guests copy the password instead of auto-joining
