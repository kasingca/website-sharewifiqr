The idea

What is a Wi-Fi QR code?

A Wi-Fi QR code is a small square your guests point their phone camera at to get online. No reading a password off the router, no typing sixteen characters with someone looking over your shoulder.

Share Wifi QR turns your network name, password and security type into a code you can print, frame and put where people will see it.

Choose a direct code to join in one tap, or a tracked code to count every scan and change the password later without reprinting.

Two kinds of code

Direct or tracked: pick what matters

Phones can only join straight from the camera when the details are inside the code. Counting scans needs a link instead. So we offer both.

Direct code

Joins in one tap

Your network name and password live inside the QR. The phone offers to join as soon as the camera sees it.

  • One-tap join on iPhone and Android
  • Works without the internet, forever
  • Nothing is logged when it's scanned
  • No scan counts
  • Reprint it if your password changes

Tracked code

Counts every scan

The QR opens a short Share Wifi QR link that shows your network and password with a one-tap copy button.

  • See how many times it's been scanned
  • Change the password without reprinting
  • Switch it off whenever you like
  • Guests copy the password instead of auto-joining

Common questions

Frequently asked questions

What's the difference between a direct code and a tracked code?

A direct code stores your network name and password inside the QR code, so a phone camera offers to join straight away. A tracked code stores a short Share Wifi QR link: scanning it shows your network and password, each scan is counted in your portal, and you can change the details without reprinting.

Do my guests need an app?

No. The built-in camera reads QR codes on iPhone (iOS 11 and later) and most Android phones (Android 10 and later). Older Android phones can use Google Lens.

Which security type should I choose?

Most routers use WPA2 or WPA3, so choose WPA/WPA2/WPA3. Choose WEP only for very old routers, and None for open networks.

Where do I create and manage my codes?

In the portal at portal.sharewifiqr.com. Use Log in at the top of any page.
